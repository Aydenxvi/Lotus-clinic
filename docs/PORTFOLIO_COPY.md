# LOTUS CLINIC — Ready-to-use portfolio descriptions

These descriptions assume **you personally understand and can explain the code**. Do not present demo functionality as real clinical deployment.

## English — short CV entry

**LOTUS CLINIC — Full-stack web application (portfolio)**
Built a responsive clinic booking and operations demo with vanilla JavaScript, Express, Prisma and MySQL. Implemented role-based patient/doctor/admin flows, transactional appointment booking, consultation documentation, prescriptions, laboratory requests, pharmacy inventory and automated API smoke checks. Deployed the frontend and API on Render with an Aiven-hosted database.

**Stack:** HTML, CSS, JavaScript, Node.js, Express, Prisma ORM, MySQL, GitHub Actions, Render, Aiven.

## Русский — описание проекта для резюме

**LOTUS CLINIC — full-stack веб-приложение для клиники (учебный проект)**
Разработал адаптивный сайт и серверное API на JavaScript, Express и Prisma с базой MySQL. Реализовал регистрацию пациентов, онлайн-запись, роли пациента/врача/главного врача, электронную историю консультаций, назначения лекарств и анализов, управление кабинетами и складом. Настроил облачное размещение на Render и Aiven, добавил автоматические проверки API.

## English — interview answer (approximately 40 seconds)

LOTUS CLINIC is my full-stack portfolio project. It covers the workflow from selecting a doctor and booking a slot through a doctor's consultation and an administrator's clinic operations. I built it with a framework-free frontend, Node.js/Express, Prisma and MySQL, focusing on server-side authorization and consistent shared data rather than browser-only mock state. I also added safe read-only deployment checks and GitHub Actions. It is a fictional-data demo, and I would not position it as compliant production healthcare software.

## Good claims vs. unsupported claims

**Safe to say:** implemented role-based routes; built a relational data model; deployed a live demo; read-only public smoke test has 18 checks; tested end-to-end with fictional records.

**Do not claim without additional independent verification:** hospital-grade security; medical certification; GDPR/HIPAA compliance; zero security vulnerabilities; guaranteed uptime; validated electronic health records; real patients; complete accessibility audit.
