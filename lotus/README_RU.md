# LOTUS CLINIC — доработанная версия сайта

Это **ваш исходный проект из архива lotus-site.6zip.zip**, а не отдельный шаблон. Сохранены существующие медицинские отделения, врачи, контакты, логика записи, личный кабинет пациента и кабинет сотрудников.

## Что изменено

- `index.html`: полностью переработанная главная по новому фиолетово-зелёному макету с логотипом, крупным слоганом, зелёным блоком контактов, быстрыми действиями, статистикой, карточками врачей и отделений, отзывами, шагами записи.
- `css/redesign.css`: новая единая система оформления для **всех страниц**, с адаптацией под телефон и планшет.
- `js/ui-icons.js`: локальные SVG-иконки без внешней библиотеки.
- `js/app.js`: переработанные сквозные шапка и футер, сохранены существующие JS-утилиты.
- Все HTML-страницы подключают новую CSS и JS в правильном порядке.
- `department.html`: удалён повторный атрибут id у main.
- В главной устранено дублирование `id="reviews"`.
- `js/data.js` (исходные врачи, телефоны, отделения и прочие данные) не изменён.

В карточках врачей используются **настоящие имена из вашего проекта**, а вместо выдуманных фотографий — инициалы. Если реальные изображения будут добавлены в проект, их можно подключить отдельно.

## Как открыть

Распакуйте ZIP, затем откройте `lotus/index.html` в браузере. Для проверки всех функций удобнее запустить локальный сервер, например:

```
cd lotus
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Важно перед реальной публикацией клиники

Проект, который вы прислали, — **статический прототип с демонстрационными функциями**. Например, записи и аккаунты хранятся на стороне браузера (`localStorage`/`sessionStorage`), а демонстрационная логика сотрудников присутствует в клиентском JavaScript. Это не является безопасным продакшен-бэкендом для реальных медицинских данных, поэтому перед запуском настоящей клиники нужны защищённая серверная авторизация, база данных, разграничение доступа и проверка публичных медицинских сведений.
